> Премиальный веб-дашборд в стиле **Glassmorphism** для управления проектами, дедлайнами, клиентами (Мини-CRM с воронкой продаж), задачами и финансами. Разработан для фрилансеров, разработчиков и digital-агентств.

---

## ✨ Ключевые возможности

### 💎 Футуристичный Glassmorphism UI
- Неоновые акцентные темы оформления (**Cyan**, **Purple**, **Emerald**, **Blue**, **Rose**, **Amber**, **Indigo**).
- Анимированное фоновое свечение (**Ambient Glow**) и полупрозрачные стеклянные панели с эффектом размытия (`backdrop-blur`).
- Полная адаптивность под любые устройства (мобильные телефоны, планшеты, широкоформатные мониторы).

### 📊 Режимы отображения и навигация
1. **👥 Воронка продаж и CRM Hub (первая вкладка по умолчанию)** — управление лидами и клиентами:
   - **Интерактивная Воронка (Sales Pipeline Kanban)** с этапами *Новый контакт ➔ Созвон / Бриф ➔ Переговоры / КП ➔ Счёт / Аванс ➔ Сделка закрыта (Запуск проекта)*.
   - **Drag-and-Drop** перемещение лидов и быстрые кнопки смены стадии.
   - Подсчет потенциального объема сделок (**Deal Value**) по каждой колонке воронки.
   - **Сетка клиентской базы** с расчетом LTV (Lifetime Value), напоминаниями о контактах (**Follow-up**), ссылками в Telegram и запуском проектов в 1 клик (**«🚀 В проект»**).
2. **⚡ Активные проекты (Канбан, Сетка, Таблица)**:
   - **Канбан-доска 2.0 (Kanban View)** — интерактивный **Drag-and-Drop** перенос карточек между стадиями (*Бэклог ➔ В работе ➔ На проверке ➔ Ждёт оплаты ➔ Ждёт клиента / На паузе ➔ Завершено*).
   - **Колонка «Ждёт клиента»**: фиксация блокеров (сбор данных, созвон) без сжигания дедлайнов для параллельной работы над другими задачами.
   - **Сетка карточек (Grid View)** — информативные карточки проектов с прогресс-баром, дедлайнами, индикатором предоплаты и долга клиента.
   - **Таблица (Table View)** — компактный сортируемый список по всем параметрам (название, заказчик, дата сдачи, готовность, бюджет, полученная предоплата, долг).
3. **📦 Архив проектов (Archive View)** — изолированное хранилище завершенных и отмененных проектов с возможностью восстановления в 1 клик, очистки и раздельной финансовой аналитики.

### 💰 Финансовый трекер и управление предоплатой
- Учет общей суммы контракта, внесенного аванса и оставшегося долга клиента.
- **Быстрый расчет предоплаты в 1 клик**: `0%`, `30%`, `50%` (половина), `100%` (полная оплата) или произвольная сумма.
- Пошаговый график траншей и платежей с отметками о получении средств.
- Верхний аналитический блок денежного потока (**Cashflow rate**).

### 🏷️ Категории, статусы и приоритеты
- Поддерживаемые категории проектов:
  - 🎨 **Дизайн / UI/UX**
  - 🎬 **Мультимедиа**
  - 🌐 **Лендинг**
  - ⚡ **Веб-сервис**
  - 🤖 **Автоматизация / Бот**
  - 🏢 **Fullstack / CRM**
  - 📱 **Мобильное приложение**
  - 💼 **Консалтинг / Аудит**
- Статусы: `Бэклог`, `В работе`, `На проверке`, `Ждёт оплаты`, `Завершён`, `На паузе`, `Отменён`.
- Приоритеты с весовой сортировкой: `🟢 Низкий`, `🔵 Средний`, `🟡 Высокий`, `🔥 Срочно!`.

### 🎯 Детализация проекта (Drill-Down)
- **Чек-лист задач** с интерактивным конфетти-эффектом 🎉 при выполнении каждой задачи.
- **Ключевые вехи (Milestones)** с процентным прогрессом.
- **Ссылки и стенды** (Figma, GitHub, Staging / Live, Документация, Чаты).
- **Блокнот заметок и ТЗ** клиента.

### 💾 Сохранение, Бэкап и Восстановление
- Автоматическое сохранение изменений в `LocalStorage` браузера.
- Экспорт всей базы проектов в единый `JSON` файл.
- Импорт проектов из `JSON` с валидацией данных.
- Быстрый сброс к стартовым 5 демонстрационным проектам.

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 18+ (рекомендуется Node.js 20+)
- npm, pnpm или yarn

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/vsanyanov-ux/project-tracker.git
   cd project-tracker
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу [http://localhost:5173](http://localhost:5173).

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
