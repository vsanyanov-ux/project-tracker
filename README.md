> Премиальный веб-дашборд в стиле **Glassmorphism** для управления проектами, дедлайнами, клиентами (Мини-CRM с воронкой продаж), задачами, финансами, встроенным **AI Copilot (DeepSeek / AI-Tunnel)** и модулем **RACI Соло-фреймворк**. Разработан для фрилансеров, разработчиков, соло-фаундеров и digital/AI-агентств.

---

## ✨ Ключевые возможности

### 💎 Футуристичный Glassmorphism UI
- Неоновые акцентные темы оформления (**Cyan**, **Purple**, **Emerald**, **Blue**, **Rose**, **Amber**, **Indigo**).
- Анимированное фоновое свечение (**Ambient Glow**) и полупрозрачные стеклянные панели с эффектом размытия (`backdrop-blur`).
- Полная адаптивность под любые устройства (мобильные телефоны, планшеты, широкоформатные мониторы).

### 📊 Режимы отображения и навигация
1. **👥 Воронка продаж и CRM Hub (первая вкладка по умолчанию)** — управление лидами и клиентами:
   - **Интерактивная Воронка (Sales Pipeline Kanban)** с этапами *Новый контакт ➔ Созвон / Бриф ➔ Переговоры / КП ➔ Счёт / Аванс ➔ Сделка закрыта (Запуск проекта)*.
   - **Drag-and-Drop** перемещение лидов и быстрые кнопки смены стадии.
   - Подсчет потенциального объема сделок (**Deal Value**) по каждой колонке воронки.
   - **Сетка клиентской базы** с расчетом LTV (Lifetime Value), напоминаниями о контактах (**Follow-up**), быстрым выбором клиента, компании и ЛПР из справочника (с поддержкой произвольного ввода), прямыми ссылками в **WhatsApp**, **MAX** и **Telegram** и запуском проектов в 1 клик (**«🚀 В проект»**).
2. **⚡ Активные проекты (Канбан, Сетка, Таблица)**:
   - **Канбан-доска 2.0 (Kanban View)** — интерактивный **Drag-and-Drop** перенос карточек между стадиями (*Бэклог ➔ В работе ➔ На проверке ➔ Ждёт оплаты ➔ Ждёт клиента / На паузе ➔ Завершено*).
   - **Колонка «Ждёт клиента»**: фиксация блокеров (сбор данных, созвон) без сжигания дедлайнов для параллельной работы над другими задачами.
   - **Сетка карточек (Grid View)** — информативные карточки проектов с прогресс-баром, дедлайнами, индикатором предоплаты и долга клиента.
   - **Таблица (Table View)** — компактный сортируемый список по всем параметрам (название, заказчик, дата сдачи, готовность, бюджет, полученная предоплата, долг).
3. **📦 Архив проектов (Archive View)** — изолированное хранилище завершенных и отмененных проектов с возможностью восстановления в 1 клик, очистки и раздельной финансовой аналитики.
4. **🛡️ RACI Соло-режим (Governance & QA для ИИ-агентств)** — операционная система разделения ролей для соло-фаундеров:
   - **Интерактивный чекер «3 Контрольных Вопроса перед действием»** со стоп-краном для защиты от несанкционированных массовых рассылок без письменного согласия клиента и пилота на 20–50 контактов.
   - **Интерактивная Матрица RACI** по 8 ключевым задачам с фильтрацией по ролям (`Founder`, `Product Owner`, `Engineer`, `Клиент-косметолог`) и опциональной колонкой Администратора клиники.
   - **4 Артефакта минимальной системы**: *Карточка клиента (Паспорт кампании)*, *Чек-лист запуска (QA & 152-ФЗ)*, *Журнал решений (Decision Log)* и *Еженедельный отчёт (Воронка возврата и выручки)* с копированием отчета для WhatsApp в 1 клик.

### 🤖 AI Copilot (DeepSeek & AI-Tunnel)
- **AI-Декомпозиция проекта (`Project Breakdown`)** — генерация структуры чек-листов задач, вех, оценки бюджета и графика платежей по описанию проекта.
- **Client Copilot** — генерация готовых статус-апдейтов, уведомлений о завершении этапа и напоминаний об оплате для отправки клиенту.
- **Risk Advisor** — AI-диагностика узких мест, дедлайнов, кассовых разрывов и оценка состояния проекта (health-score).
- **Поддержка провайдеров AI-Tunnel и DeepSeek Direct** (плюс Custom OpenAI-compatible URL): работа из РФ без VPN, проверка подключения, отображение баланса в рублях в реальном времени и выбор моделей (`deepseek-chat`, `deepseek-r1` / `deepseek-reasoner`, `gpt-4o-mini`).

### 💰 Финансовый трекер и управление предоплатой
- Учет общей суммы контракта, внесенного аванса и оставшегося долга клиента.
- **Быстрый расчет предоплаты в 1 клик**: `0%`, `30%`, `50%` (половина), `100%` (полная оплата) или произвольная сумма.
- Пошаговый график траншей и платежей с отметками о получении средств.
- Верхний аналитический блок денежного потока (**Cashflow rate**).

### 🏷️ Категории, статусы и приоритеты
- Поддерживаемые категории проектов:
  - 🎨 **Дизайн / UI/UX**
  - 🎬 **Мультимедиа**
  - 🌐 **Лендинг**
  - ⚡ **Веб-сервис**
  - 🤖 **Автоматизация / Бот**
  - 🏢 **Fullstack / CRM**
  - 📱 **Мобильное приложение**
  - 💼 **Консалтинг / Аудит**
- Статусы: `Бэклог`, `В работе`, `На проверке`, `Ждёт оплаты`, `Завершён`, `На паузе`, `Отменён`.
- Приоритеты с весовой сортировкой: `🟢 Низкий`, `🔵 Средний`, `🟡 Высокий`, `🔥 Срочно!`.

### 🎯 Детализация проекта (Drill-Down)
- **Чек-лист задач** с интерактивным конфетти-эффектом 🎉 при выполнении каждой задачи.
- **Ключевые вехи (Milestones)** с процентным прогрессом.
- **Ссылки и стенды** (Figma, GitHub, Staging / Live, Документация, Чаты).
- **Блокнот заметок и ТЗ** клиента.

### 💾 Сохранение, Бэкап и Восстановление
- Автоматическое сохранение проектов, CRM-клиентов, настроек AI и артефактов RACI в `LocalStorage` браузера.
- Экспорт базы проектов и CRM-клиентов в единый `JSON` файл.
- Импорт проектов и клиентов из `JSON` с валидацией данных и обратной совместимостью.
- Быстрый сброс к стартовым демонстрационным проектам и эталонным данным RACI.

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 18+ (рекомендуется Node.js 20+)
- npm, pnpm или yarn

### Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/vsanyanov-ux/project-tracker.git
   cd project-tracker
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите сервер разработки**:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу [http://localhost:5173](http://localhost:5173).

4. **Сборка для продакшена**:
   ```bash
   npm run build
   ```
